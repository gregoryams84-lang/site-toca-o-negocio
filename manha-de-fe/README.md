# Manhã de Fé 🌅

Aplicativo devocional católico diário para brasileiros 40+ (foco em idosos).
Leve, offline primeiro, desenhado para quem não domina bem o celular — e
encantador.

> *"Você já viu sua Manhã de Fé hoje?"*

- **Documento oficial do projeto (especificação):** [`docs/ESPECIFICACAO.md`](docs/ESPECIFICACAO.md)
- Stack: Flutter (Android 7.0+ e iOS, um código só)
- Modelo: assinatura única de R$ 9,90/ano, tudo liberado

Este diretório vive dentro do repositório do site apenas como casa temporária
da documentação e do início do desenvolvimento; o app pode ser movido para um
repositório próprio quando fizer sentido.
